# 推送内容 · 深色/浅色模式 PRD

## 1. 背景与目标

App 端通知在系统浅色（Light）与深色（Dark）主题下的展示效果不同，同一套文案与配图在两种主题下的可读性、视觉观感往往无法同时达到最佳。

本需求在「新建推送任务 - 推送配置」步骤中引入 **浅色模式 / 深色模式** 切换，允许运营针对两种主题分别配置推送内容，从而在不同系统主题下都获得最佳展示效果。

## 2. 名词说明

| 名词 | 说明 |
| --- | --- |
| 浅色模式（Light） | 用户设备处于浅色主题时展示的推送内容 |
| 深色模式（Dark） | 用户设备处于深色主题时展示的推送内容 |
| 模式独立配置 | 两种模式各自保存一套内容配置，互不影响 |

## 3. 功能范围

### 3.1 模式切换 Tab

- 在「推送配置」内容区顶部提供分段切换控件（Tab），选项为「浅色模式」「深色模式」。
- **默认选中浅色模式。**
- 切换 Tab 时，下方内容配置区实时切换为对应模式的数据；已填写内容不会因切换而丢失。

### 3.2 每个模式下可独立配置的字段

在浅色模式与深色模式下，均可独立配置以下字段：

| 字段 | 说明 |
| --- | --- |
| 内容填充 | 自定义 / 内容模板（选择内容模板时可配置文案组、发送规则） |
| 通知标题 | 支持插入参数、多语言配置，最长 50 字 |
| 通知内容 | 支持插入参数、多语言配置，最长 200 字 |
| 通知图片 | 自定义上传 / 列表随机 / 无 |

### 3.3 共享配置（不区分模式）

以下配置为整条推送共享，不随模式切换而改变：

- 实验类型
- 点击跳转
- 基础样式、展开式通知
- 提示音、是否震动

## 4. 交互与规则

1. 默认进入时展示浅色模式配置。
2. 两种模式的内容配置各自独立存储，切换 Tab 不清空另一模式已填内容。
3. 复制推送状态时，两种模式的配置一并复制。
4. 实时预览区展示**当前所选模式**下的标题、内容与图片。
5. 多语言抽屉作用于当前所选模式的标题与内容。
6. **富文本预览渲染**：通知标题、通知内容支持富文本标签（如 `<font color='#808080'>...</font>` 设置文字颜色），预览区需按富文本解析后展示实际效果（如指定颜色的文字），而非原样展示标签源码。

## 4.1 富文本预览规则

- 输入框中仍以富文本源码形式编辑（如 `<font color='#808080'>New puzzle awaits!</font>`），字数统计按源码长度计算。
- 预览区对标题、内容进行富文本解析后渲染，支持的标签以客户端实际支持范围为准（当前至少支持 `<font color>` 文字颜色）。
- 富文本渲染需在浅色模式与深色模式预览下均生效。
- 出于安全考虑，仅渲染白名单内的富文本标签，其余标签/脚本需转义或过滤，避免 XSS。

## 5. 校验规则

- 浅色模式的通知标题、通知内容为**必填**。
- 深色模式为**可选**：若不单独配置，则由客户端在深色主题下沿用浅色模式内容或按平台默认策略展示。
- 「内容填充」选择内容模板时，标题/内容输入框禁用，走模板文案。

## 6. 数据结构（前端）

推送状态在原有字段基础上新增 `dark` 子对象保存深色模式配置，浅色模式沿用顶层字段：

```json
{
  "id": "1",
  "contentFillMode": "custom",
  "notificationTitle": "浅色标题",
  "notificationContent": "浅色内容",
  "notificationImage": { "type": "custom", "url": "", "material": "" },
  "i18nTexts": [],
  "dark": {
    "contentFillMode": "custom",
    "notificationTitle": "深色标题",
    "notificationContent": "深色内容",
    "notificationImage": { "type": "custom", "url": "", "material": "" },
    "i18nTexts": []
  }
}
```

提交时 `push_content_config.states[]` 每个状态附带 `dark` 字段，结构与浅色内容对齐（`content_fill_mode`、`title`、`content`、`image` 等）。

## 7. 非目标（本期不做）

- 不做深色/浅色预览背景的自动主题渲染切换（预览外观保持现状）。
- 不做深色模式内容缺失时的智能自动生成。
