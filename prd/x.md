# 订阅任务表单字段规范

| 表单字段 | 必填 | 约束规则 | 差异化渲染逻辑 |
|---|---|---|---|
| 任务名称 | ✅ | ≤ 50 字符；同一 Topic 下名称不可重复；空值拦截 | SQL / API / 离线上传通用 |
| 任务状态（单选） | ✅ | 默认选中「开启」，可选「关闭」；控制定时调度启停 | 三类通用 |
| 任务类型（单选互斥） | ✅ | 新建时可切换 SQL / API / 离线上传；编辑模式锁定置灰不可修改 | 切换类型自动切换下方专属配置区块：<br>1. SQL：调度时间 + SQL 代码编辑器<br>2. API：调度时间 + API 地址 / 鉴权配置<br>3. 离线上传：调度时间 + CSV 文件上传控件 |
| 调度时间 | ✅ | 周期固定为「每天」；时分输入框默认 `00:00`；校验时分合法 | 三类通用，代表每日定点批量同步 Topic 订阅用户 |
| 执行脚本（SQL 专属） | ✅ | 多行代码输入框；查询结果仅允许返回 `uid`、`production_id` 两列；禁止 DDL / 删改表语句；提交前语法校验 | 仅 SQL 类型展示 |
