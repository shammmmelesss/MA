# PRD：推送任务 - 推送配置「展开式通知」

## 1. 功能概述

「展开式通知」用于配置推送在通知栏下拉展开后所呈现的富媒体样式。基础通知（标题 + 内容 + 小图标）之外，可选择以文本、大图、背景图等形式增强展示效果，提升点击率与转化。

本文档重点说明「大图」样式下的三种取图方式及其配置项（对应下图：大图 + 顺序发送 + 图片组 + 偏移量）。

---

## 2. 使用场景

- 活动大促推送配「大图」海报，展开后展示完整活动主视觉
- 图片组按日期顺序轮播，不同日期推送展示不同素材（如签到日历、连续活动）
- 单次活动使用「自定义」上传专属素材

---

## 3. 功能模块

### 3.1 展开类型（expandType）

顶层选择展开式通知的展示形态。

| 选项 | 值 | 说明 |
|------|------|------|
| 禁用 | `disabled` | 不启用展开式通知（默认） |
| 文本 | `text` | 展开后展示更多文本 |
| 大图 | `large_image` | 展开后展示一张大图，见 3.2 |
| 背景图 | `bg_image` | 通知以图片作为背景 |
| 背景色值 | `bg_color` | 通知以纯色作为背景 |
| 右侧大图 | `right_image` | 通知右侧展示配图 |

> 切换展开类型时，会清空大图相关的取图方式、图片组、偏移量、自定义图片等配置。

### 3.2 大图取图方式（expandImageMode）

当「展开类型」选择 `大图（large_image）` 时，出现取图方式选择，默认 `列表随机`。

| 选项 | 值 | 说明 | 关联配置 |
|------|------|------|----------|
| 列表随机 | `random` | 推送时从所选图片组中随机取一张 | 图片组 |
| 顺序发送 | `date_map` | 从图片组中按顺序取图（配合偏移量按日期依次发送） | 图片组、偏移量 |
| 自定义 | `custom` | 手动上传单张图片 | 图片上传 |

> 切换取图方式时，会清空图片组、偏移量、自定义图片等下级配置。

### 3.3 图片组（expandImageGroupId）

取图方式为 `列表随机` 或 `顺序发送` 时显示。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 图片组（expandImageGroupId） | 图片组 ID | 是 | 从当前项目下「大图」类型的图片组中选择；无可选项时提示「暂无图片组」 |

- 图片组数据按当前项目（`project_id`）与图片类型 `large` 拉取。
- 图片组内素材的管理在「素材管理 - 图片素材」模块维护。

### 3.4 偏移量（expandImageOffset）

仅取图方式为 `顺序发送（date_map）` 时显示。

| 字段 | 类型 | 必填 | 默认 | 约束 | 说明 |
|------|------|------|------|------|------|
| 偏移量（expandImageOffset） | 整数 | 是 | `0` | 最小 0，步长 1，非负整数 | 从图片组的第几张开始顺序发送 |

- 含义：顺序发送时的起始位置偏移。`0` 表示从图片组第 1 张开始。
- 典型用法：连续多日活动中，通过设置偏移量对齐「活动第 N 天」应展示的素材。

### 3.5 自定义图片（expandImageUrl）

仅取图方式为 `自定义（custom）` 时显示。

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| 图片上传（expandImageUrl） | 图片 | 是 | 格式 jpg/jpeg/png，大小 ≤ 1MB | 上传单张大图；已上传后按钮变为「重新上传」并展示缩略图预览 |

---

## 4. 字段联动关系

```
展开类型 = 大图
  └─ 取图方式
       ├─ 列表随机  → 图片组
       ├─ 顺序发送  → 图片组 + 偏移量
       └─ 自定义    → 图片上传（+ 缩略图预览）
```

- 任一上级选项变更时，其下级配置均被重置，避免残留脏数据。

---

## 5. 数据结构（state.style）

| 字段 | 类型 | 说明 |
|------|------|------|
| `expandType` | string | 展开类型，见 3.1 |
| `expandImageMode` | string | 大图取图方式，见 3.2 |
| `expandImageGroupId` | number | 选中的图片组 ID |
| `expandImageOffset` | number | 顺序发送偏移量，默认 0 |
| `expandImageUrl` | string | 自定义上传图片的地址 |

---

## 6. 校验规则

| 场景 | 规则 |
|------|------|
| 大图 + 列表随机 | 图片组必选 |
| 大图 + 顺序发送 | 图片组必选；偏移量为非负整数（默认 0） |
| 大图 + 自定义 | 必须上传 1 张图片；格式 jpg/jpeg/png 且 ≤ 1MB |
